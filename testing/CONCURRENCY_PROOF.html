Two-Layer Protection Mechanism

L1 MongoDB Partial Unique Index

Database-level hard stop. Enforced atomically by the storage engine — no application code can bypass it.

appointmentSchema.index( { doctor: 1, startsAt: 1 }, { unique: true, partialFilterExpression: { status: 'booked' } } );

The partial filter means cancelled slots don't block rebooking.

L2 In-Transaction Re-Check

Availability check runs inside the MongoDB transaction — no TOCTOU gap between check and write.
