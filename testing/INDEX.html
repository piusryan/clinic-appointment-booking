How to Run Everything

From the backend/ directory

  • npm test Run the full Jest suite (all 15 files, 197 tests). Uses an in-memory MongoDB replica set — no external DB needed.
  • npm run test:concurrency Race condition proof — 50 authenticated patients, 1 slot. Requires MongoDB running as a replica set on localhost:27017. Cleans up its own fixtures automatically.
  • npm run test:naive Phase A vs Phase B comparison — shows naive check-then-write producing 48 rows vs the index producing 1. Uses the real DB. Cleans up automatically.
  • npm run purge:race If the concurrency test was interrupted mid-run, use this to clean up any leftover race fixtures from the database without running the full test again.
  • npx jest --runInBand __tests__/rbac.test.ts Run just the RBAC suite in isolation.
  • npx jest --runInBand __tests__/token-security.test.ts Run just the token security suite.
  • npx jest --runInBand __tests__/cancel-rebook.test.ts Run just the cancel-rebook partial index suite.
