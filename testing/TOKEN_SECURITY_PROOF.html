Tampered Signature
401 Unauthorized

Appending a character to the JWT signature or flipping the last byte. Both rejected — the server never reveals why.

Wrong Secret
401 Unauthorized

Token signed with a randomly-generated secret instead of the server's JWT_ACCESS_SECRET. Signature verification fails immediately.

Expired Token
401 Unauthorized

Token issued with expiresIn: '-1s' (already expired at signing). Rejected before any DB lookup.

Non-Existent User ID
401 Unauthorized

Validly signed token carrying a sub that matches no document in the database. The DB check closes the gap.

Refresh After Password Change
401 Unauthorized

Password change bumps refreshTokenVersion. Any refresh token issued before the change is instantly invalidated — including on other devices.

Multi-Session Invalidation
Both sessions → 401

Two simultaneous sessions (different "devices"). A password change on session 1 kills session 2 as well — the version bump is global to the user.

Deactivated Account
401 Unauthorized

A valid, unexpired token for an account where isActive=false. The server checks the DB on every request, not just at login.

Missing / Malformed Header
401 Unauthorized

No Authorization header, and a token sent without the Bearer prefix. Both return the standard error envelope with x-error-code: Unauthorized.
