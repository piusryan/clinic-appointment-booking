What this proves: The partialFilterExpression: { status: 'booked' } on the (doctor, startsAt) unique index means only booked rows participate in the uniqueness constraint. A cancelled row does not hold the key — so the slot is genuinely freed. Without this partial filter, cancelled appointments would permanently block the slot from ever being rebooked.
